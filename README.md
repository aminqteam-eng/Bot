# 💎 Bitpin Price Bot — Neon Royal

ربات تلگرام قیمت ارز دیجیتال (بیت‌پین) با کارت‌های تصویری نئون + مقایسهٔ تصویری تا ۱۰ ارز هم‌زمان.

## قابلیت‌ها
- قیمت لحظه‌ای +۶۵۰ ارز (تومان/ریال/دلار)، تبدیل، خرید با تومان، برترین‌ها، وضعیت بازار
- کارت تصویری هر ارز: لوگوی واقعی + نمودار نئون ۲۴ساعته
- مقایسهٔ تصویری چند ارز در یک عکس رتبه‌بندی‌شده:
  - `تون، بیت کوین، اتریوم` (با کاما یا خط جدید)
  - `تون بیت کوین اتریوم سولانا` (فقط فاصله، حداقل ۳ ارز)
  - `/compare BTC ETH TON SOL` (دستور صریح، حتی برای ۲ ارز)

## دیپلوی روی Railway (از طریق گیت‌هاب)

1. این پوشه رو در یک ریپوی گیت‌هاب (خصوصی پیشنهاد می‌شه) پوش کن.
2. توی Railway → **New Project → Deploy from GitHub repo** → ریپو رو انتخاب کن.
3. تب **Variables** رو باز کن و بزن:
   ```
   BOT_TOKEN = توکن ربات از BotFather
   ```
4. Railway خودش از `requirements.txt` نصب می‌کنه و طبق `Procfile` با دستور
   `worker: python bot.py` ران‌ش می‌کنه (نیازی به تنظیم پورت نیست چون ربات polling ـه، نه وب‌سرور).
5. دیپلوی که تموم شد، لاگ باید بنویسه: `🤖 Bot started (Neon Royal + Compare)...`

> ⚠️ توکن رو مستقیم توی کد نذار و پوش نکن — از Variables توی Railway (یا فایل `.env` لوکال، طبق نمونهٔ
> `.env.example`) استفاده کن. اگه `BOT_TOKEN` ست نباشه، ربات با یک پیام خطای واضح بالا نمیاد.

## اجرای لوکال
```bash
pip install -r requirements.txt
export BOT_TOKEN="توکن-ربات-شما"
python bot.py
```

## افزودن ارز جدید
یک خط به دیکشنری `CG_IDS` (شناسهٔ CoinGecko) و در صورت نیاز به `ALIASES` (اسم فارسی) اضافه کن — لوگو
و نمودار به‌صورت خودکار برای ارزهای داخل `CG_IDS` فعال می‌شن.
